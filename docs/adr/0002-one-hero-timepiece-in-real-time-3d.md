# One Hero Timepiece in real-time 3D

Only the Hero Timepiece is an interactive 3D object; every other Timepiece is shown in still images rendered from 3D models. Real-time 3D is what sets the site apart from a template, but each interactive model costs download size and phone performance, and only free CC-BY models are available, so one well-tuned model beats several mediocre ones.

## Considered Options

- **Pre-rendered image sequence scrubbed on scroll**: looks perfect but cannot be rotated or recoloured, which rules out Colourways and the live-time hands.
- **Every Timepiece in 3D**: too heavy for a mid-range phone, and there are not enough suitable free models.

## Consequences

- The Hero Timepiece persists on screen through the first three acts of Home (arrival, turn, Exploded View); the rest of the page is still, editorial sections, with one exception: the craftsmanship section shows the escapement at work in real-time 3D. It is not a Timepiece and cannot be turned or recoloured; it is a second free CC-BY model playing its own animation, included because its file fits the phone budget, and it is a Still wherever the 3D is not.
- Phones get a lighter model and simpler effects, with a still-image fallback on very weak devices.
